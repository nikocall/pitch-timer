# Pitch Timer

A full-screen 5-minute countdown for pitches and Q&A, in MCAST branding.

**Open it:** https://nikocall.github.io/pitch-timer/

- The screen flashes amber at **2:00** and orange at **1:00** remaining, with beeps.
- At **0:00** it pulses red and counts overtime.

| Key | Action |
|---|---|
| Space | Start / pause |
| R | Reset |
| P / Q | Pitch / Q&A label (resets to 5:00) |
| ↑ / ↓ | ±1 minute |
| M | Sound on/off |
| F | Full screen |

Add `?test` to the URL to run at 20× speed for a rehearsal.
